# Brune & Co. — Coffee shop showcase site

A fictional coffee shop landing page built to explore modern, animated UI patterns — from an interactive table reservation map to a terminal-style order ticket animation.

**[Live demo →](https://brune-co.vercel.app/)**

## Features

- Animated hero with a "ticket-to-card" order confirmation sequence
- Interactive table reservation with a floor plan layout (client-side simulation)
- Responsive menu with categorized pricing
- Fully typed with TypeScript
- Accessible semantic HTML (proper heading hierarchy, aria labels on interactive elements)

## Stack

- React + Vite
- TypeScript
- Tailwind CSS v4

## Running locally

```bash
git clone https://github.com/Hene-W/Brune-Co.git
cd brune-and-co
npm install
npm run dev
```

## Note

This is a portfolio/demo project. The reservation system is simulated client-side and does not persist data or send real confirmations.
